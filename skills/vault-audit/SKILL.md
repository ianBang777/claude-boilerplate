# vault-audit — 볼트 정합성 점검

대상: `/Users/ian/dev/MyfairDevVault`. 점검 전 볼트 루트의 `CLAUDE.md`(스키마·규칙)와 `태그 사전.md`(허용 태그)를 읽는다.

## 점검 항목

대상 폴더는 `정책/`, `정보/`, `기능개발/`만. (`_` 접두 파일, `메모/`, `TODO/`, `Reports/`, `Clippings/`, `Templates/`는 면제)

1. **frontmatter 누락**: 파일이 `---`로 시작하지 않거나 `tags`/`date`가 없는 노트.
2. **태그 사전 위반**: `태그 사전.md`의 2축(`도메인/*`, `기술/*`)에 없는 태그. 3레벨 태그는 상위 2레벨이 사전에 있으면 통과 (예: `기술/FE/tanstack-query` → `기술/FE` 확인).
3. **고아 노트**: 다른 노트와 링크(본문 `[[...]]` 또는 frontmatter `관련`)가 하나도 없는 노트 — 들어오는 링크·나가는 링크 모두 0인 것.
4. **깨진 링크**: `[[대상]]`이 실제 파일로 해석되지 않는 것 (볼트 전체 대상, 링크는 파일명 기준 매칭). 단 코드 블록·인라인 코드 안의 예시 링크는 제외 — 특히 루트 `CLAUDE.md`는 문법 예시가 있으므로 이 항목에서 뺀다.
5. **방치된 진행중**: `status: 진행중`인데 `updated`(없으면 `date`)가 30일 이상 지난 기능개발 문서.
6. **status 누락**: 기능개발 문서 중 `status`가 없는 것.
7. **`관련` 형식 오류**: frontmatter `관련`이 따옴표 위키링크 배열(`["[[...]]"]`)이 아닌 것 — 일반 텍스트는 그래프에 연결되지 않는다.
8. **메모 승격 대기**: `메모/`에 30일 이상(파일 mtime 기준) 머문 노트 — 정보/기능개발로 승격하거나 폐기할 후보로 목록화한다.
9. **미소화 클리핑**: `Clippings/` 노트 중 다른 노트(정보·기능개발)에서 한 번도 `[[링크]]`로 참조되지 않은 것 — 총 개수와 오래된 순 상위 5개를 보여준다. 요약·승격되면 정보 노트가 클리핑을 링크하게 되므로 참조 여부가 소화의 지표다.

## 실행 방법

- bash(grep/awk)로 일괄 스캔한다. 노트 전체를 읽지 않는다 (frontmatter는 파일 상단 ~10줄).
- 조사 자체는 노이즈가 크므로 서브에이전트(Explore)에 위임해도 좋다.

## 출력

항목별 위반 목록을 표로 리포트하고, **자동 수정 가능한 것**(형식 오류·깨진 링크 unlink)과 **사용자 판단 필요한 것**(태그 신설, status 확정, 고아 노트 연결처)을 구분한다. 수정은 사용자 확인 후 수행한다.
