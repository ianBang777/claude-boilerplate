# Todo

옵시디언 Tasks 플러그인 포맷의 데일리 할 일 목록을 Claude 커맨드로 관리한다.

## 경로

| 이름    | 경로                                                      |
| ------- | --------------------------------------------------------- |
| VAULT   | `/Users/ian/Documents/MyfairDevVault`                      |
| LIST    | `$VAULT/TODO/TodoList.md` — 데일리 목록 (단일 진실 공급원) |
| ARCHIVE | `$VAULT/TODO/Archive/YYYY-MM.md` — 완료 히스토리 (월별)    |
| NOTES   | `$VAULT/TODO/Notes/<이름>.md` — 할일별 상세 노트           |

오늘 날짜는 `date +%F`로 얻는다. 추측하지 않는다.

## Tasks 포맷 규칙 (읽기·쓰기 공통)

한 줄 = 한 태스크. 순서: 체크박스 → 내용 → `[[노트링크]]` → `#태그` →
우선순위 → 🔁 반복 → 날짜들 → ✅ 완료일.

- 상태: `- [ ]` 할 일 / `- [/]` 진행 중 / `- [x]` 완료 / `- [-]` 취소
- 날짜: `📅` 마감(due) / `⏳` 예정(scheduled) / `🛫` 시작 / `✅` 완료일
- 우선순위: `🔺` 최고 / `⏫` 높음 / `🔼` 중상 / (없음) 중간 / `🔽` 낮음 / `⏬` 최저

기존 줄을 수정할 때 이 메타데이터를 임의로 재정렬하거나 삭제하지 않는다.
LIST의 tasks 쿼리 블록(```tasks)은 절대 수정하지 않는다.

## 0단계 — 자동 롤오버 (모든 커맨드 실행 전 공통)

LIST 헤더(`# 🗓️ YYYY-MM-DD 데일리`)의 날짜가 오늘과 다르면 먼저:

1. `- [x]` · `- [-]` 항목 중 **✅ 날짜가 오늘 이전**인 것을 완료 월의
   `ARCHIVE/YYYY-MM.md`로 이동(끝에 append, 완료일 오름차순 유지).
   ✅ 날짜가 없으면 헤더 날짜를 완료일로 간주한다.
   아카이브 파일이 없으면 `# 🗄️ YYYY-MM 완료 아카이브` 헤더로 생성한다.
2. 헤더 날짜를 오늘로 갱신한다.
3. 사용자에게 한 줄로 알린다: `🗓️ 7/1 → 7/3 롤오버: 완료 N건 아카이브 이관`

✅ 날짜가 오늘인 완료 항목과 미완료(`- [ ]`, `- [/]`) 항목은 그대로 둔다.

## 커맨드

### `/todo` — 오늘 요약

LIST를 읽고, 볼트 전체(Archive 제외)에서 `📅` 달린 미완료 태스크를
grep해서 overdue를 수집한 뒤 출력한다:

```markdown
## 🗓️ 2026-07-03

**진행 중** (있을 때만)
- [/] ...

**오늘 할 일** (우선순위 높은 순)
- ⏫ ...
- ...

**🔥 지난 마감** (있을 때만, 파일 위치 표기)
- ... 📅 2026-06-28 (기능개발/xxx.md)

**🎉 오늘 완료** (있을 때만)
- ✅ ...
```

빈 섹션은 생략한다. 전부 비었으면 "오늘 할 일이 없습니다"라고만 한다.

### `/todo add <내용>` — 할 일 추가

1. 입력에서 마감·예정·우선순위·태그를 먼저 파싱한다.
   - "내일까지" → `📅 <내일>` / "금요일부터" → `⏳ <날짜>`
   - "급함·중요" → `⏫`, "여유·나중에" → `🔽`
   - 프로젝트 언급 시 기존 태그(`#기능개발` `#support-tech` 등) 재사용
2. **입력에 없는 항목은 AskUserQuestion으로 한 번에 묻는다** (이미
   파싱된 항목은 다시 묻지 않는다):
   - **기한**: 오늘 / 내일 / 이번 주 / 없음 (Other로 직접 입력)
   - **우선순위**: 높음 ⏫ / 중간 (기본) / 낮음 🔽
   - **노트 추가 여부**: 예 / 아니오
3. Tasks 포맷으로 변환해 LIST의 `## ✅ 오늘 할 일` 섹션 끝에 추가한다.
   예: `- [ ] 부스 QA #기능개발 ⏫ 📅 2026-07-04`
4. 노트 추가 = 예 → 이어서 `note` 플로우를 실행한다.

추가한 줄을 그대로 보여준다.

### `/todo done <내용>` — 완료 처리

내용과 부분 일치하는 미완료 항목을 LIST에서 찾는다.

- 1개 매칭 → `- [x]`로 바꾸고 끝에 ` ✅ <오늘>`을 붙인다.
- 여러 개 매칭 → 후보를 나열하고 어느 것인지 확인한다.
- 0개 → LIST의 미완료 목록을 보여주고 확인한다.

즉시 아카이브로 옮기지 않는다 — "오늘 완료"로 남았다가 다음 롤오버 때
이관된다. 연결된 `[[노트]]`가 있으면 "완료 정리를 노트에 남길까요?"라고
한 번 묻는다.

### `/todo note <할일>` — 상세 노트 생성·연결

1. 대상 태스크를 LIST에서 찾는다 (매칭 규칙은 done과 동일).
2. **연관 링크를 묻는다**: "연관된 노션·슬랙·문서 링크가 있으면
   알려주세요 (없으면 '없음')." — URL은 자유 입력이므로
   AskUserQuestion 대신 일반 질문으로 받는다. 대화에 이미 링크가
   있으면 묻지 말고 그것을 쓴다.
3. `NOTES/<간결한 이름>.md`를 아래 템플릿으로 생성한다. 대화에 배경
   정보가 있으면 채워 넣고, 링크가 없다고 하면 관련 링크 섹션의 해당
   줄은 뺀다.

   ```markdown
   ---
   tags:
     - todo
     - <프로젝트 태그 (태스크의 #태그와 동일, # 제외)>
   ---

   # <할일 이름>

   > 태스크: [[TodoList]] · 생성 2026-07-03

   ## 배경

   ## 관련 링크

   - 노션: <URL>
   - 슬랙: <URL>
   - 관련 노트: [[<볼트 내 관련 문서>]]

   ## 메모

   ## 완료 정리
   ```

4. 태스크 줄의 내용 텍스트 바로 뒤(태그·이모지 앞)에 `[[<이름>]]`을
   삽입한다.

이미 같은 이름의 노트가 있으면 새로 만들지 말고 링크만 연결한다.

## 그래프 연결 규칙 (옵시디언 Graph View)

연관관계가 그래프에 드러나도록:

- **태스크 줄과 노트가 같은 프로젝트 태그를 공유한다** — 태스크에
  `#기능개발`이 있으면 노트 frontmatter tags에도 `기능개발`을 넣는다.
  그래프에서 태그를 켜면 같은 프로젝트끼리 묶여 보인다.
- **노트는 항상 `[[TodoList]]`로 역링크**를 갖는다 (템플릿의 태스크
  줄). TodoList ↔ 노트 양방향 연결.
- **볼트 내 관련 문서는 `[[위키링크]]`로 연결한다** — 노트 생성 시
  `기능개발/`, `메모/`, `정보/` 폴더에서 같은 주제의 기존 문서를
  검색(grep)해서, 있으면 "관련 노트"로 링크를 제안한다.
- 외부 링크(노션·슬랙 URL)는 그래프에 나타나지 않으므로 관련 링크
  섹션에 담고, 볼트 내 연결은 반드시 위키링크·태그로 만든다.

### `/todo history <키워드|기간>` — 완료 히스토리 검색

`ARCHIVE/` 전체(+ LIST의 오늘 완료)에서 검색한다.

- 키워드 → 내용 grep (예: `/todo history 부스`)
- 기간 → ✅ 날짜 필터 (예: `/todo history 6월`, `지난주`)
- 둘 다 없으면 최근 2주 완료 목록

완료일 내림차순으로 출력하고, `[[노트]]`가 연결된 항목은 노트 경로를 함께
보여준다. 요청이 "언제 뭘 어떻게 했는지"면 연결된 노트의 완료 정리 내용을
읽어 요약에 포함한다.

## 공통 규칙

- LIST · ARCHIVE · NOTES 외의 볼트 파일은 수정하지 않는다 (읽기는 허용).
- 태스크 텍스트는 사용자가 쓴 그대로 보존한다. 오타 교정·재작성 금지.
- 옵시디언이 실행 중일 필요 없다. 파일 직접 조작으로 충분하다.
