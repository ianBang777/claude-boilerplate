## 적용 우선순위

충돌 시: **명시적 사용자 지시 > 00 하네스 원칙 > 프로젝트 관습 > 01~05 일반
규칙**. 06은 규칙이 아니라 완료 시점의 점검 게이트다. 원칙은 도구이지
의식(ritual)이 아니다. 맥락에 맞게 판단하되, 어길 땐 이유를 밝힌다.
