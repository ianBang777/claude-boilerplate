# 공용 개발 규칙 (Rules)

어느 프로젝트에서나 재사용 가능한 공용 규칙 모음입니다. 새 프로젝트에는 이
`rules/` 폴더를 통째로 복사해 사용하세요.

**자동 로드되지 않습니다.** 상위 `CLAUDE.md`가 이 폴더를 `@import`하지 않으므로,
아래 표의 "언제 보는지"를 보고 필요한 시점에 해당 파일을 직접 읽어 적용합니다.
작업 방식·우선순위는 `CLAUDE.md`가 소유하며, 이 폴더는 도메인 규칙만 담습니다.

## 구성

| 파일                                                     | 내용                                         | 언제 보는지                       |

`CLAUDE.md`의 「충돌 시 우선순위」를 따릅니다. 이 폴더는 별도 서열을 두지 않습니다.
